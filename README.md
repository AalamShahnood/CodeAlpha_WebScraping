# CodeAlpha Web Scraping

## Project Overview

This project was completed as part of my CodeAlpha internship.

The objective of this task was to extract structured information from a publicly available website using Python web scraping techniques.

## Technologies Used

- Python
- Requests
- BeautifulSoup
- Pandas
- CSV

## What This Project Does

The scraper collects:

- Quotes
- Authors
- Tags

from multiple pages of a publicly available website.

The extracted data is then organized into a structured CSV dataset.

## Features

- Web page data extraction
- HTML parsing using BeautifulSoup
- Multiple-page scraping
- Data structuring using Pandas
- CSV dataset generation

## Dataset

The final dataset contains 100 scraped records with the following columns:

- Quote
- Author
- Tags
